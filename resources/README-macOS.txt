Pulse Edit — Quick Start (macOS)
================================

1. DRAG PulseEdit.app to your Applications folder
   (Do NOT open it from Downloads — macOS will block features)

2. Open DaVinci Resolve Studio
   - Create or open a project
   - Go to Edit page with a timeline

3. Open PulseEdit.app from Applications
   - Enter your license key
   - Select audio track → Analyze → Edit
